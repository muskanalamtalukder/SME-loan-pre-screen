# SME Loan Pre-Screen System

This project is a simple web application for pre-screening SME loan applications.  
It allows users to enter business details, check required documents, and view automated pre-screen results.

Features
- Business name, turnover and investment input
- Document checklist (KYC, Income Proof, Business Proof)
- Automatic document status indicator
- Animated menu with Profile / Help / Logout
- Dashboard showing pre-screen results
- Clean, centered UI with HDFC-styled theme

##  Technologies Used
- React + Vite
- JavaScript (ES6)
- CSS (custom styling)
- Git & GitHub for version control
